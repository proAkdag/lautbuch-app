# Mein Lautbuch · App

Ein Leselern-Buch nach dem Elif-Bâ-Aufbau: Silbentafeln, Wörter mit Bildern, ein Weg durch die Laute. Als Home-Bildschirm-App (PWA) für das eigene iPad.

**Diese App enthält keine personenbezogenen Daten.** Der Lernstand entsteht erst auf dem Gerät (Browser-Speicher) und verlässt es nur, wenn die Begleitung ihn selbst sichert (Datei) oder per QR-Code auf ein eigenes Gerät überträgt. Kein Tracking, keine Anfragen an fremde Server, kein CDN; nach dem ersten Öffnen läuft alles offline.

## Installieren und aktualisieren

Safari → Seite öffnen → Teilen → „Zum Home-Bildschirm“. Eine neue Fassung lädt die App im Hintergrund, wenn Netz da ist; übernommen wird sie mit „Aktualisieren“ in der Begleit-Schublade. Geänderte Bilder werden einzeln nachgeladen.
